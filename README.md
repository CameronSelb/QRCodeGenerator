# QR Code Generator

A simple and lightweight QR code generator built with HTML, CSS, and JavaScript. Enter text or a URL and instantly generate a QR code that can be downloaded and used anywhere.

## Features

- Generate QR codes from text or URLs
- Instant QR code generation
- Download generated QR codes
- Simple and responsive interface
- Lightweight with no framework or build process required
- Client-side generation

## Technologies

- HTML5
- CSS3
- JavaScript
- QR Code library

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/CameronSelb/QRCodeGenerator.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd QRCodeGenerator
```

### 3. Run the project

Open `index.html` in your browser.

No additional dependencies or build tools are required.

## How It Works

The application takes user input and uses a QR code generation library to convert the provided text or URL into a scannable QR code.

Everything is handled directly in the browser, keeping the application lightweight and simple to use.

## Purpose

This project was created as a small JavaScript project to practise DOM manipulation, user input handling, working with external libraries, and dynamically generating content in the browser.
